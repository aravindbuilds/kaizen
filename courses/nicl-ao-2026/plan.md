# NICL AO 2026 — Study Plan (2h weekday + 5h weekend)

Prelims 17 Nov (Eng 30 + Reas 35 + Quant 35, 60 min, −0.25, sectional cutoffs).
Mains 22 Dec (250 marks + Descriptive Essay/Précis/Comprehension 30).

## Weekly rhythm
- **Mon**: Quant drill 70′ + English 40′ + formulas 10′
- **Tue**: Reasoning 70′ + GA/IT 40′ + headlines 10′
- **Wed**: Quant 70′ + Computer Knowledge 40′ + shortcuts 10′
- **Thu**: Reasoning 70′ + English 40′ + vocab 10′
- **Fri**: Weakest topic 60′ + GA/CK or Technical 40′ + flashcards 20′
- **Sat**: Full mock 60′ + 2h analysis (log errors by topic) + PYQ paper
- **Sun**: New concept 2h + sectional test 2h + flashcards 1h

## Phase A — Prelims (5 weeks)
1. Basics: simplification + series, inequality + syllogism, error detection.
2. Arithmetic (SI-CI, boat, train) + seating + DBMS/SQL (IT).
3. DI sets + 1 puzzle/day (8-min cap) + Networks.
4. Speed only: 20-min sectional tests, no new theory.
5. Taper: one sectional/day + flashcards. Sleep before the exam.

Exam order: English easy → Reasoning easy → Quant simplification → puzzles/DI.
Target: 65–75 attempts at 85% accuracy.

## Phase B — Mains
- Mon Quant-Adv DI • Tue high puzzles • Wed GA capsules • Thu English • Fri Technical/CK.
- Sun: typed descriptive (alternate Essay / Précis+Comprehension).
- 4 full Mains mocks. Order: GA → English → CK → Quant → Reasoning → Technical → Descriptive.
